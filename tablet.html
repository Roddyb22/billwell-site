Use Billwell on a tablet

Install Billwell from your browser so it opens like an app — full screen, from your home screen, Start menu, or app drawer. This works on Android tablets, Windows tablets and laptops, Chromebooks, and Amazon Fire tablets.

Open mybillwell.com in the browser for your device, sign in, then follow the steps below. In the web app, Help also has an Install button when your browser can install it directly.

Android tablets (Chrome)

  1. Open Billwell in Chrome.
  2. Tap the menu (three dots) in the upper right.
  3. Tap Install app, or Add to Home screen if that is what you see.
  4. Confirm Install. Billwell appears on your home screen.

Samsung Internet

  1. Open Billwell in Samsung Internet.
  2. Tap the menu (three lines).
  3. Tap Add page to, then Home screen — or Install app if you see it.
  4. Confirm. The icon appears on your home screen.

Windows tablets and laptops (Edge)

  1. Open Billwell in Microsoft Edge.
  2. Tap or click Settings and more (the … menu).
  3. Open Apps, then choose Install this site as an app.
  4. Confirm. Billwell appears in your Start menu and opens in its own window.

Windows (Chrome) and Chromebooks

  1. Open Billwell in Chrome.
  2. In the address bar, tap the Install icon (a computer with a down arrow). If you do not see it, open the Chrome menu and choose Install Billwell, Install app, or Save and share › Install page as app.
  3. Confirm Install. On a Chromebook, Billwell shows up in your app drawer and can be pinned to the shelf. On Windows, it appears in the Start menu.

Amazon Fire tablets (Silk)

  1. Open Billwell in the Silk browser.
  2. Tap the menu.
  3. Tap Add to Home.
  4. Confirm. The icon appears on your home screen.

Your team

Each person on your team can install Billwell on their own tablet. Technician logins — so each tech signs in as themselves — are coming soon.

If you do not see an install option, you can still use Billwell in the browser at mybillwell.com.
